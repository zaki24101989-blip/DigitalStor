# مسلم — Quran Web App

الخطوة الأولى من تطبيق مسلم:
- React + Vite
- واجهة عربية RTL
- قائمة 114 سورة
- بحث بالسورة أو الرقم
- الوضع الليلي
- المفضلة داخل الجلسة
- الورد اليومي
- الأذكار وعداد التسبيح
- Bottom Navigation للجوال

## التشغيل
```bash
npm install
npm run dev
```

الخطوة التالية: ربط AlQuran Cloud API وإضافة صفحة السورة والنص القرآني والتفسير والصوت.
